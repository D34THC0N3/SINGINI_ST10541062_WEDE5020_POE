# Obsidian Motors

my WEDE5020 POE website. its a fake car shop for super rare cars lol. all black with some gold, plus vids everywhere.

## pages

index.html is the home page, big video at the top. collection.html has the cars. about.html says how we get the cars. consign.html is the form if u wanna sell your car. contact.html is the form plus a map to find us. privacy.html and terms.html are the boring legal pages. 404.html shows when a page is missing.

## how to open it

just double click index.html, it opens in your browser. thats the easiest way tbh.

if that doesnt work for some reason:

python -m http.server 8000

then go to http://localhost:8000 in chrome.

no build or install stuff needed. just html, css and js. the gsap files are in the assets folder so it works even with no wifi.
